# Portfolio Dashboard

A full-stack portfolio dashboard built as part of a Full Stack Developer assignment.

## Tech Stack

### Frontend

- Next.js 15
- TypeScript
- Tailwind CSS
- TanStack Query
- Recharts

### Backend

- Node.js
- Express
- TypeScript
- Yahoo Finance API
- XLSX

## Features

- Excel portfolio parsing
- Live market data integration
- Portfolio analytics
- Sector allocation
- Interactive charts
- Responsive dashboard

## Getting Started

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Environment Variables

### Backend

```env
PORT=5000
```

### Frontend

```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api/v1
```
